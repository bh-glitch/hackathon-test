# Study Room agent instructions

Read README.md before implementation. It defines the product, ownership, shared interfaces and demo checks.

- Work on the branch assigned to your coder: Bhavya, Ishan, Vansh or Arnav.
- Bhavya creates the initial scaffold and shared contracts before feature agents start implementation.
- Stay within your owned files. Coordinate changes to shared types, dependencies, lockfiles and other owners' files in the task issue.
- Implement only the agreed MVP. Do not substitute the stack or add extra features.
- Confirm pending product decisions before implementing behavior that depends on them.
- Run appropriate checks and report actual results and blockers.
- Never commit secrets, .env files, node_modules or SQLite database files.
- Preserve other agents' changes. Do not force-push shared branches.
- Open a pull request when GitHub access is authorized and available. Feature agents do not merge into main; Bhavya coordinates integration.

The four coders run independent agents on their own computers. Do not spawn additional agents unless explicitly requested.
